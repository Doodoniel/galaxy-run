# Galaxy Run · Summer reboot

A supportive revision lesson for learners who finished GoGetter 2 before summer and are preparing for GoGetter 3. The original artwork, space setting, story, colours and board are preserved.

## Run

- `npm ci`
- `npm run dev`
- `npm run build`
- `npm run lint` (existing code has non-blocking warnings)

## Lesson and teacher script

Open `public/teacher-guide.html`, or Teacher → «Сценарий урока» in the game. The editable Russian source is `docs/teacher-script-ru.md`. The guide includes a 60-minute script, four-card oral warm-up, exact prompts and sample answers, adaptations for 45 minutes or two lessons, answer keys and references.

## Sequence

1. Get ready: crew → radio check, including asking for help.
2. Remember: picture vocabulary → illustrated story (text can be hidden) → six meaning/form models.
3. Try it: word tasks → story/meteors → 12-item revision checkpoint → optional word boost → board game.
4. Create: design a planet → communicate original ideas and respond to a visitor → write a postcard → receive feedback and reflect.
5. Celebrate: personal practice evidence and a learning passport.

The board remains mixed practice, not free production. The independent planet invitation is production. All activities remain accessible for teachers to adapt pacing. Allow 5–8 seconds of thinking time. Do not force every item into one hour; preserve time for speaking.

## Scope and assessment

Supplementary GoGetter 2 revision: habits, actions now, quantities, comparisons, past events and plans, leading towards GoGetter 3. The game does not claim full course coverage, publisher approval, CEFR certification or a measured GSE score. Course ranges and pedagogical sources are documented in the guide.

Stars are participation/game rewards, separate from auto-checked accuracy. Board chance affects finishing order. Speaking criteria are checked by a teacher or partner; written messages are not automatically graded. Self-reflection is explicitly separate. Mistakes do not cause a language penalty; asking for help is modelled.

All artwork under `public/art` is unchanged. Progress is stored only in this browser. Mode switches preserve the crew. Solo changes the answer input method; remove extra pilots on Crew if appropriate. For a large class, profiles represent teams rather than individual learners.
